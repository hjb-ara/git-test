# プロジェクト名: 動作確認サンプルアプリ

## 概要
動作確認サンプル用アプリ。最低限のGUIの起動の確認と、バージョンの表示等を確認する。

## 技術スタック
- プロジェクト管理（および仮想環境）: uv（インストール済）
- Python: 3.14（uvにより設定。`python-version`参照）
- GUI: PySide6（インストール済）
- exeファイル化： Nuitka（インストール済）
- 尚、uvの仮想環境とPythonのインタプリタは`.envrc`のPathの示す位置にある。

## 設計
- アプリのGUIデザインは、PySide6-Designerで作成した`src/ui/app_window.ui`をそのまま使用する。

## バージョン管理について
- バージョン管理については、`git`コマンドから取得しアプリケーションに組み込むものとする。
- バージョン番号の取得方法(`get_app_version.py`)と利用方法`use_app_version.py`のサンプルをdocs/specs/sample`ディレクトリに配置するので参照のこと。

## `main`の設計
- 表示サンプルとしてのアプリなので、今回は`src/main.py`のみで完結して構わない。
- ただし、バージョン管理ができているか確認したいので、ウインドウのタイトル部分にバージョン番号を挿入できるようにする。
- アプリの体裁を保つように、ボタンを一つだけ追加し、ボタンを押し下げするとアプリケーションを終了するようにする。
