# Architecture AI Rules

## ディレクトリ方針・ファイルについて
- （`main.py`含む）すべてのPythonソースコードは `src/` 配下に配置すること。
- エントリポイントは`src/main.py`を起点とすること。
- `src/`配下以外に`main.py`がある場合は削除すること。
- `import`におけるパスはエントリポイントを起点とし、パスに`src.`をプレフィックスとして付けないこと。
- `*.ui` ファイルは `src/ui/` に配置し、`Path(__file__).parent` の相対パスで読み込むこと。
- `*.ui`ファイルと対になる`*.py`ファイルを作成する際は、（拡張子を除いた）同様のファイル名とし、`*.ui`と同じディレクトリに作成すること。（拡張子が異なっても、対となるファイルは同一ディレクトリの方がメンテナンス性が高いため）
- アセットについては`src/assets/`配下に配置すること。

## コマンドの実行について
- コマンドの実行は、基本的には`Git Bash`を使用すること。

## コーディングルール
- コーディングにおいて、変数および関数等には型定義（型アノテーション）を導入すること。
- GUIについての規約については、`ui_components.md`を参照すること。
- Slotとなる関数には、`@Slot()`デコレータを利用すること。

## 例外処理について
- エラーハンドリング（例外処理）は必ず記述すること。
